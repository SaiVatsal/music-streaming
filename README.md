# Project 33: High-Fidelity Music Streaming Engine (CyanWave)

A 24-bit lossless audio streaming and spatial DSP platform built with React 18, Vite, TailwindCSS, and Zustand.

## Features
- **Dark Neon-Cyan Theme**: Lossless audio aesthetics (`#050811`, `#06b6d4`, `#0f172a`) with Space Grotesk and JetBrains Mono typography.
- **Master Lossless Catalog**: Hi-Res FLAC 24-bit/96kHz & MQA 192kHz bitrate badges across Synthwave, Cyberpunk, Ambient Chill, and Nu-Disco.
- **Synchronized Karaoke Lyrics Engine**: Real-time line-by-line lyric tracking synced to acoustic playback timestamps.
- **Waveform & Frequency Visualizer Bars**: Animated CSS keyframe frequency spectrum meters.
- **Offline Storage Vault**: Simulated local cache manager with disk space usage gauges.
- **Custom Playlist Sequencing**: Create and organize custom playback sets.

## Getting Started
```bash
npm install
npm run dev
```
